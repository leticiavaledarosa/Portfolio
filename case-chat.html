Quando o portfólio responde por você

Como construí um assistente virtual embutido diretamente no portfólio — sem IA, sem backend, zero custo — usando apenas HTML, CSS e JavaScript.

Por Leticia Vale da Rosa
Analista de Inteligência de Mercado & Dados

Portfólios tradicionais são passivos. O avaliador entra, lê, sai. Não há interação, não há conversa, não há forma do projeto falar por si mesmo. Queria mudar isso — criar algo que apresentasse minha trajetória e projetos de forma humana, memorável e completamente diferente do que se vê por aí.

A solução foi um assistente virtual estilo WhatsApp, embutido diretamente no HTML do portfólio. Sem servidor, sem API, sem custo mensal. Puro front-end.

O desafio

Como analista de dados, meu trabalho é traduzir informação complexa em algo compreensível. Fazia sentido aplicar esse mesmo princípio ao portfólio: como apresentar trajetória, projetos e serviços de forma que qualquer pessoa entenda — sem precisar ler tudo?

A resposta veio de uma observação simples: todo mundo já sabe usar um chat. É uma interface familiar, intuitiva, que convida à interação. Por que não usar isso?

A interface mais acessível que existe é aquela que as pessoas já usam todos os dias. O chat é isso. — Leticia Vale da Rosa

A técnica por trás

Toda a lógica do chat é construída com funções JavaScript puras — sem frameworks, sem bibliotecas. O segredo está no timing: cada mensagem tem um delay calculado para simular uma digitação real, com o indicador de "digitando..." aparecendo antes de cada resposta.

JavaScript 
// Mostra mensagem com animação de digitação
function cIn(txt, av, delay, then) {
  setTimeout(function() {
    cShowT(); // mostra "digitando..."
    setTimeout(function() {
      cHideT();
      cMsg('in', txt, av);
      if (then) then(); // callback encadeado
    }, 900);
  }, delay);
}

O resultado

O assistente abre sozinho, apresenta a Leticia em menos de 30 segundos e guia o visitante pelo portfólio de forma não-linear. Quem tem pressa clica em "Projetos" direto. Quem quer conhecer mais pergunta sobre a trajetória. Cada pessoa navega do seu jeito.

O maior aprendizado foi perceber que tecnologia simples bem aplicada supera soluções complexas. Não precisei de IA, de API, de banco de dados. Precisei entender o comportamento do usuário e traduzir isso em código.
